# 📸 Photo guide (for our photographer)

Drop each photo into this folder **with exactly the file name below**.
The page picks it up automatically. Until a photo exists, the page
shows a labelled placeholder, so nothing breaks.

## Rules

1. **Consent:** anyone whose face is recognisable must agree to appear. Get it in writing (a WhatsApp "yes" screenshot is better than nothing).
2. **Real GaU only:** no stock photos.
3. **Light:** shoot early morning or late afternoon. Midday sun washes everything out.
4. **Size:** resize to about **1200 px on the longest side** and keep each file **under 300 KB**, because visitors are on mobile data. Free tool: [squoosh.app](https://squoosh.app).
5. **Names:** lower-case, no spaces, `.jpg`, exactly as in the table.
