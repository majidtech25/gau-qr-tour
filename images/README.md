# 📸 Photo guide (for our photographer)

Drop each photo into this folder **with exactly the file name below**.
The page picks it up automatically. Until a photo exists, the page
shows a labelled placeholder, so nothing breaks.

**Hero slideshow tips:** use the same framing distance in all four, so the crossfade feels smooth.
Keep the letters in roughly the same place in each shot. The page fades between them every 5 seconds.
Slides with no photo yet are skipped automatically.

**Page weight:** the photos above add up to about 1.6 MB, inside our ~2 MB budget.
(`og-cover.jpg` is only loaded by WhatsApp/Facebook for the preview, not by the page.)

## Rules

1. **Consent:** anyone whose face is recognisable must agree to appear. Get it in writing (a WhatsApp "yes" screenshot is better than nothing).
2. **Real GaU only:** no stock photos.
3. **Light:** shoot early morning or late afternoon. Midday sun washes everything out.
4. **Size:** resize to the pixel size in the table and keep each file under its limit, because visitors are on mobile data. Free tool: [squoosh.app](https://squoosh.app).
5. **Names:** lower-case, no spaces, `.jpg`, exactly as in the table.
